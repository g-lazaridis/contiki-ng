# Contributing

This is a research fork of [Contiki-NG](https://github.com/contiki-ng/contiki-ng),
published as the implementation behind an MSc dissertation. It is not actively
developed, and there is no plan to upstream it as-is.

Issues and pull requests are welcome, but please do not expect the
responsiveness of a maintained project. If your change is to Contiki-NG itself
rather than to the LoRa work here, it belongs upstream — see
[the Contiki-NG contribution guidelines](https://docs.contiki-ng.org/en/develop/doc/project/Contributing.html).
