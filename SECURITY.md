# Security Policy

This is an unmaintained research fork of
[Contiki-NG](https://github.com/contiki-ng/contiki-ng). It carries no security
support and should not be deployed anywhere that matters: among other things,
the LoRa link runs without TSCH link-layer security.

If you find a vulnerability **in upstream Contiki-NG**, report it to the
upstream project at security@contiki-ng.org — not here.

If you find one in the code that is specific to this fork (the WM1110 board
port, the LR1110 radio driver, or the Orchestra rules), please open an issue on
this repository.
